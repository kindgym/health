# Health
운동 회원들에게 운동 기구 설명 및 영상으로의 사용 설명, 헬스장 이벤트 공지 등. 헬스장 기구를 잘못된 자세로 하는 게 아니라 정자세로 알려드리기 위한 것을 목표로 잡고 있다.

## 기구 도감 페이지

`index.html` — 센터 보유 기구 34종을 분류별로 정리한 단독 웹페이지입니다.
파일 하나로 동작하며 별도 빌드나 서버가 필요 없습니다.

- 분류: 유산소 / 프리웨이트 / 상체 머신 / 하체 머신 / 케이블·기능성
- 기구별 **자세히 보기** → 타깃 근육 · 세팅 체크 · 동작 순서 · 코칭 큐 · 주의사항 · 영상
- 영상은 링크 카드 방식(새 탭). 아직 등록 전인 기구는 유튜브 검색 링크가 걸린 **영상 자리**로 표시됩니다.
- 우측 상단 **편집** → 기구 추가, 영상 링크 등록, 목록에서 숨기기

편집으로 추가한 내용은 그 브라우저에만 저장됩니다.
모든 회원에게 보이게 하려면 **내보내기**로 받은 JSON을 전달해 `index.html`에 반영하세요.

### GitHub Pages로 공개하기
Settings → Pages → Source: `Deploy from a branch` → 브랜치와 `/ (root)` 선택 → Save.
1~2분 뒤 `https://<사용자명>.github.io/Health/` 에서 열립니다.
